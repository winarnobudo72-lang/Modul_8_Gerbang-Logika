Deskripsi Singkat

Modul ini mengajak peserta didik mengenali cara perangkat digital mengambil keputusan sederhana. Gerbang logika menerima satu atau lebih masukan biner (0 dan 1), lalu menghasilkan keluaran berdasarkan aturan tertentu.

2. Tujuan Pembelajaran

  1. Menjelaskan konsep logika biner dan fungsi gerbang logika dasar.
  2. Mengenali simbol serta aturan kerja gerbang NOT, AND, OR, NAND, NOR, XOR, dan XNOR.
  3. Membaca dan menyusun tabel kebenaran berdasarkan kombinasi masukan.
  4. Memprediksi keluaran gerbang logika dari kondisi input yang diberikan.
  5. Menghubungkan gerbang logika dengan contoh pemanfaatan perangkat digital dalam kehidupan sehari-hari.
  6. Menyelesaikan LKPD dan kuis secara mandiri, cermat, serta bertanggung jawab.

3. Materi: Gerbang Logika Dasar

Sistem digital umumnya menggunakan dua keadaan logika: 0 (LOW / salah / mati) dan 1 (HIGH / benar / aktif). Gerbang logika mengolah keadaan ini sesuai aturan tertentu.

Istilah penting: Input adalah masukan (misalnya A dan B), output adalah hasil (Y), dan tabel kebenaran menunjukkan output untuk setiap kombinasi input.

Ingat: NOT memakai satu input. Gerbang AND, OR, NAND, NOR, XOR, dan XNOR pada modul ini memakai dua input. NAND dan NOR disebut gerbang universal karena kombinasi gerbang sejenis dapat membentuk fungsi logika lain.

4. Simulasi Input–Output

Pilih gerbang, lalu ubah nilai input A dan B. Output akan dihitung otomatis. Untuk NOT, input B tidak digunakan.

Masukan
A = 0, B = 0
Gerbang
AND
Keluaran Y
0
● Output LOW / Mati

AND menghasilkan 1 hanya jika kedua input bernilai 1.

Coba tantangan

  1. Atur AND dengan A=1 dan B=0. Catat output.
  2. Atur OR dengan A=0 dan B=1. Catat output.
  3. Atur XOR dengan A=1 dan B=1. Catat output.
  4. Atur NOT dengan A=0. Catat output.

5. Contoh Penerapan dalam Kehidupan

AND — syarat ganda

Simulasi: mesin dapat berjalan jika tombol mulai ditekan dan pelindung terpasang. Kedua kondisi harus benar.

OR — salah satu syarat

Alarm dapat aktif jika sensor pintu atau sensor jendela mendeteksi kondisi tertentu.

NOT — pembalik keadaan

Sinyal “tidak terdeteksi” dapat dibentuk dari kebalikan sinyal deteksi, sesuai rancangan rangkaian.

NAND / NOR

Dapat digunakan sebagai bagian rangkaian pengendali, pengunci logika, dan pembentuk fungsi digital.

XOR — kondisi berbeda

Indikator menyala ketika dua masukan berbeda, misalnya untuk mendeteksi ketidaksamaan dua bit.

XNOR — kondisi sama

Rangkaian pembanding bit dapat memberi keluaran 1 jika kedua bit yang dibandingkan sama.

Contoh di atas merupakan model konseptual. Implementasi nyata bergantung pada sensor, rangkaian, dan program yang digunakan.

8. Panel Guru / Admin

Panel ini membantu guru meninjau hasil yang tersimpan pada browser/perangkat yang digunakan. Penyimpanan localStorage bersifat lokal; data tidak otomatis terkirim ke komputer guru atau server. Untuk menggabungkan jawaban dari banyak perangkat, diperlukan backend/server atau pengumpulan file dari setiap perangkat.

Privasi: jangan gunakan perangkat bersama tanpa izin. Ekspor CSV berisi nama, kelas, skor, waktu, dan jawaban siswa. Simpan file dengan aman.
